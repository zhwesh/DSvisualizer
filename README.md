# DSvisualizer
## 功能介绍
本项目使用前端技术对常见数据结构与算法进行可视化，用户可对数组、链表、哈希表、平衡树等数据结构进行任意增删改查操作，且对于每个数据结构的增删改查算法，项目都进行了详细的步骤划分，用户可以使用流程控制面板观察具体逻辑

### 可视化
直观展示各数据结构的形态、特性与细节

### 步骤划分
以AVL树插入操作为例，它可分为以下步骤：
- 前n步：每步将要插入的数字与当前节点比较，决定向左或向右移动
- 将新节点挂在对应的叶子上
- 后m步：每步检查左右子树高度，进行左旋或右旋

### 流程控制
通过流程控制面板，细致观察单步操作
- 暂停：停止执行
- 单步执行：进行一步操作
- 播放：每隔固定时间进行一步操作
- 快进：连续快速执行各步操作

# 使用方法

## 源码下载
克隆仓库：
```
git clone https://github.com/zhwesh/DSvisualizer.git
```

安装依赖：
```
npm install
```

启动开发环境（热更新网页）：
```
npm run dev
```

## 使用项目
下载Release包，解压后在根目录用任意静态文件服务器打开`index.html`（直接双击本地文件会被浏览器拦截，ES模块脚本无法通过file://加载）

或在项目源码根目录下执行：
```
npm run build
npm run preview
```
编译产物输出至`dist/`，`npm run preview` 会以静态服务器方式在本地预览；也可将`dist/`部署到任意静态服务器

# 收录的数据结构与算法

## 数据结构
- 线性表：数组、单链表、循环链表、双向链表
- 线性结构：队列、双端队列、栈（数组与链式存储实现）
- 哈希表
- 树形结构
  - 二叉搜索树：二叉搜索树、AVL树、红黑树（自底向上）、替罪羊树、Treap树
  - 线段树
- 其他：并查集、字典树、树状数组

## 算法
- 线性表：二分查找、排序（冒泡排序、插入排序、快速排序、归并排序）、KMP算法
- 树形结构：二叉树的遍历（前序、中序、后序）
- 图论：最小生成树（kruskal算法、prim算法）、最短路（dijkstra算法、Floyd算法）
